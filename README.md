### 👨‍💻 What I do

I build the off-chain half of on-chain products: indexers that never miss a block, APIs that stay in sync with the chain, and frontends that make signing a transaction feel boring (in a good way).

- **Deepchain Labs** — Built the **Krown Validator Platform** end to end (NestJS + Next.js, ~75K LOC), with **$350K+ staked** through it. Gap-free, self-healing EVM indexer on a single resilient WebSocket; resumable historical backfill; a reusable wagmi + viem transaction hook.
- **VDEX** — Go backend for a perpetual DEX with **1,000+ active traders**: position netting, new trading pairs (crypto, gold, stocks) with data-source failover.

### 🔭 Currently building

**[Gapless](https://github.com/roudra323/Gapless)** — a resilient ERC-20 transfer indexer and read API: no gaps, no duplicates, survives WebSocket drops, RPC errors, reorgs and restarts. Kubernetes (kind / GKE), Terraform, GitHub Actions, Prometheus + Grafana.
