I build the off-chain half of on-chain products: indexers that never miss a block, APIs that stay in sync with the chain, and frontends that make signing a transaction feel boring (in a good way).

- **Deepchain Labs** (Jan 2026 – now): built the **Krown Validator Platform** end to end (NestJS + Next.js, ~75K LOC), with **$350K+ staked** through it. Gap-free, self-healing EVM indexer, resumable backfill, and a reusable wagmi + viem transaction hook.
- **VDEX** (2025): Go backend for a perpetual DEX with **1,000+ active traders**: position netting and new trading pairs with data-source failover.
